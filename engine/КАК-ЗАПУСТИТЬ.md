# Как это запустить

Коротко: это программа для твоего компьютера, а не для сайта.
Кидаешь ей запись звонка — получаешь отчёт.

---

## Что куда

**Движок** живёт у тебя на диске. Работает как обычная программа.
На сайт он не ставится и ставиться не должен.

**Ключи** живут в текстовом файле `.env` рядом с программой.
В консоли Яндекса ничего добавлять не нужно — сервисный аккаунт
ключи только выдаёт, хранишь их ты.

**Сайт** — отдельная история. Чтобы разбор работал через сайт,
нужен посредник на сервере (шаг 6 в `docs/SETUP-YANDEX.md`).
Это следующая задача, не эта.

## Запуск за четыре шага

### 1. Распакуй архив

Распакуй `moment-vse-narabotki.zip` куда-нибудь без русских букв в пути.
Например: `C:\moment`

Внутри будет папка `engine` — она и нужна.

### 2. Проверь, что есть Node.js

Это среда, в которой работает программа. Проверить просто: запусти
`start.bat` — если Node.js нет, он сам об этом скажет.

Если нет — скачай LTS-версию с `nodejs.org`, установи, запусти снова.

### 3. Впиши ключи

При первом запуске `start.bat` сам создаст файл `.env` и откроет
его в Блокноте. Впиши три значения после знака `=`:

```
YANDEX_FOLDER_ID=b1g...     идентификатор каталога
YANDEX_STT_KEY=AQVN...      ключ с областью speechkitStt
YANDEX_GPT_KEY=AQVN...      ключ с областью languageModels
```

Сохрани Ctrl+S и закрой Блокнот.

Ключи должны быть **разные**: у них разные области действия,
один на оба поля не подойдёт.

Идентификатор каталога берётся из адресной строки консоли:
`console.yandex.cloud/folders/b1gXXXXXXXX` — вот это `b1g…`.

### 4. Перетащи запись на start.bat

Берёшь мышкой файл с записью звонка и бросаешь прямо на `start.bat`.

Программа расшифрует запись, разберёт разговор и положит отчёт
в папку `out`. Открывается браузером.

---

## Что такое npm install

Это команда, которая скачивает библиотеки, нужные программе для работы.
Выполняется **один раз** при первой установке. `start.bat` делает это сам,
руками вводить ничего не нужно.

Если видишь в инструкциях `npm run analyze` — это то же самое, что
перетащить файл на `start.bat`, только через командную строку.

## Если не работает

Первый запуск часто падает. Самые частые причины:

| Что пишет | В чём дело |
|---|---|
| `401` или `403` | перепутаны области ключей, или в `.env` имя каталога вместо `b1g…` |
| `Нет YANDEX_FOLDER_ID` | файл `.env` не сохранён или лежит не в той папке |
| `Mock-режим` | не задан `YANDEX_STT_KEY` — программа не знает, чем распознавать |
| ошибка про формат | SpeechKit не взял этот формат записи, попробуй mp3 или wav |

Текст ошибки присылай целиком, **но вырежи из него ключи**.

## Сколько стоит один запуск

Распознавание считается по времени записи, разбор — по объёму текста.
Точные цены — в калькуляторе `yandex.cloud/ru/prices`.

Грант, который даёт Яндекс при создании платёжного аккаунта, на отладку
хватает с запасом. Один звонок стоит копейки; разорит только случайный
цикл, который гоняет распознавание в бесконечном повторе — поэтому
программа обрабатывает по одному файлу за запуск.

---

## Про логирование

В консоли SpeechKit по умолчанию включено логирование запросов —
Яндекс сохраняет у себя всё, что ты отправляешь.

Для записей чужих разговоров это надо **выключить** в настройках сервиса,
и сделать это до первого клиентского звонка, а не после.
