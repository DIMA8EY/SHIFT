## Первое действие

Прогнать настоящий звонок через движок. Всё остальное ждёт.

```
cd engine
npm install
# .env заполнить по .env.example
npm run analyze -- запись.mp3
```

Нужны: `YANDEX_FOLDER_ID` (вид `b1g…`, именно идентификатор, не имя),
`YANDEX_STT_KEY` (область `yc.ai.speechkitStt.execute`),
`YANDEX_GPT_KEY` (область `yc.ai.languageModels.execute`).

Чаще всего первый прогон падает на: перепутанных областях ключей,
имени каталога вместо идентификатора, формате аудио.

## Долги, которые надо закрыть

1. **Токен телеграм-бота открыт** в `script.js:12` — отозвать у @BotFather.
   Он в истории гита, правка файла дыру не закроет.
2. **Логирование SpeechKit** — по умолчанию Яндекс пишет все запросы.
   Для записей клиентов это надо выключить, см. ниже.
3. **Нет ключа для синтеза** — роль `tts.user` есть, ключа с областью
   `yc.ai.speechkitTts.execute` нет. Без него тренажёр нечем озвучить.
4. **Лишние ключи** — три ключа на `languageModels`, два не используются.

## Облако Момента

Функция `shiftassistance` (чат SHIFT) к Моменту отношения не имеет и не трогается.
Для Момента создаётся вторая функция `moment-api`: инструкция в `moment-api/README.md`.
Ссылка и код доступа вводятся на сайте (значок облака), в файл не вписываются.

## Очередь работ

1. Прогнать живой звонок, починить что вылезет
2. Ключ TTS, озвучить шесть реплик тренажёра один раз
3. Прокси на Cloud Functions (туда же перенести отправку формы в телеграм)
4. Страница тренажёра: проигрывание mp3 + MediaRecorder + одна отправка в конце
5. Кабинет с регистрацией — только после первых платящих клиентов

## Что решено и почему

- **Разбор на YandexGPT, не на Claude.** Один ключ, один счёт, данные
  не покидают страну. Claude точнее, включается `ANTHROPIC_API_KEY`.
- **Оценку считает код, не модель.** Один разговор всегда даёт одно число.
- **Положительный вывод без дословной цитаты снимается.** Число снятых
  печатается в отчёте — это ответ на вопрос «а вы не придумали».
- **Реплики тренажёра синтезируются один раз**, а не на каждое занятие.
- **Распознавание включается один раз в конце занятия**, а не на реплику.
