# Облачная функция для сайта Момента

Это вторая функция в твоём облаке. Первая, `shiftassistance`, отвечает посетителям
сайта SHIFT и остаётся как есть. Эта обслуживает кабинет Момента:

| Что делает | Где видно на сайте |
|---|---|
| распознаёт речь (кусками до 30 секунд) | «Загрузить» и «Тренажёр» |
| озвучивает клиента голосом Джейн («раздражённый») | «Тренажёр» |
| разбирает звонок по оценочной карте | «Загрузить» |
| разбирает тренировку | «Тренажёр» |

Ключей не нужно вообще. Функция работает от сервисного аккаунта, который ты уже создал.

---

## Создание функции, один раз, около десяти минут

Названия кнопок в консоли Яндекса могут отличаться от моих: ориентируйся на смысл.

1. **Cloud Functions → Функции → Создать функцию.** Имя: `moment-api`.
2. **Среда выполнения:** Python (у тебя 3.14, подойдёт любая от 3.10).
3. **Редактор кода → файл main.py.** Удали всё, что там есть, вставь целиком содержимое
   `moment-api/main.py`. **Точка входа:** `main.handler`.
4. **Таймаут: 90 секунд.** Память: 256 МБ. С таймаутом по умолчанию (несколько секунд)
   разбор длинного звонка не успеет.
5. **Сервисный аккаунт:** `n8n-agentadmistrator`. У него уже есть три нужные роли:
   `ai.speechkit-stt.user`, `ai.speechkit-tts.user`, `ai.languageModels.user`.
6. **Переменные окружения:**

   | Имя | Значение |
   |---|---|
   | `YC_FOLDER_ID` | `b1ggjqpo56eldi0ecdnp` (идентификатор твоего каталога) |
   | `ACCESS_CODE` | любой пароль, который придумаешь |

   `ACCESS_CODE` важен: ссылка на функцию окажется в твоём браузере и в истории,
   а каждый запрос тратит твой грант. Без кода любой, кто нашёл ссылку, расходует его.
7. **Сохранить версию.** Потом **Обзор → сделать функцию публичной**. Без этого сайт
   получит ошибку 403.
8. Скопируй **ссылку для вызова** (вида `https://functions.yandexcloud.net/…`).

## Подключение сайта

1. Открой `demo/moment/index.html` в браузере, войди.
2. Нажми **значок облака** в шапке.
3. Вставь ссылку и код доступа → **Сохранить и проверить**.
4. Должно появиться «Функция настроена», а значок станет с зелёной точкой.

Ссылка и код хранятся только в этом браузере, в файл не вписываются.

Проверка связи ничего не тратит и Яндекс не вызывает: она смотрит только настройки.
Роли аккаунта выяснятся на первом настоящем запросе.

## Если что-то не работает

Сайт показывает текст ошибки прямо на экране.

| Что видно | Что делать |
|---|---|
| «нет доступа к Яндексу: привяжите сервисный аккаунт» | в шаге 5 аккаунт не выбран |
| «не задана переменная YC_FOLDER_ID» | шаг 6 |
| «Неверный или не введён код доступа» | код на сайте не совпадает с `ACCESS_CODE` |
| «SpeechKit отклонил доступ (403)» | у аккаунта нет роли `ai.speechkit-stt.user` |
| «Не удалось связаться с функцией» | функция не публичная или ссылка скопирована не целиком |
| «Функция не ответила вовремя» | таймаут функции меньше 90 секунд |

Журнал функции (вкладка «Логи») пишет только служебное: действие и код ошибки.
Тексты разговоров и звук в журнал не попадают, это сделано намеренно.

## Ограничения

- Запись до **20 минут и 60 МБ**, один звонок за раз.
- **Стерео** (два канала, как отдаёт телефония): роли разделяются бесплатно, это лучший случай.
  **Моно**: роли определяет модель по смыслу, разбор заметно менее точный.
- Звук режется на куски по 25 секунд без нахлёста, поэтому слово на стыке может распасться.
- Тишина не отправляется на распознавание: за неё не платишь.
- Лимит: 240 кусков распознавания и 20 разборов за 10 минут с одного адреса. Это защита
  от случайного цикла, а не от целенаправленной атаки: память живёт, пока жив экземпляр функции.
- Микрофону в тренажёре нужен `https` или открытие файла с диска. По обычному `http` браузер его не даст.
